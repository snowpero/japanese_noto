GitHub 연결

GitHub Pages 주소에서 저장소를 자동 인식해. 브랜치는 main, 데이터 파일은 words.json으로 고정했어. Fine-grained Token에는 해당 저장소의 Contents: Read and write 권한이 필요해.

단어 등록 및 복습 후 GitHub에 자동 저장을 시도해. 연결이 없거나 실패하면 이 기기의 브라우저에 보관해. GitHub 토큰은 HTML이나 JSON에 넣지 마.
